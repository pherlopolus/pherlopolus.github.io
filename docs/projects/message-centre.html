Project 02 · ESP32 / networking

Message centre

A coordinator, a family of ESP32 message panels, and a practical question: how far can the network reach when each panel forwards for the next?

Current position: coordinator and universal panel source is recorded in a private development repository. The ordered forwarding package has static checks and documentation, but its full chain has not been verified on physical boards.

The system

A central coordinator handles panel identities and messages. The universal panel source targets a plain ESP32 web panel and a Waveshare 4.3-inch touchscreen variant. The panel interface and relay transport share the same broad message flow, with different display hardware.

The current experiment

The proposed topology forms a strict chain: Panel 1 talks directly to the coordinator; Panel 2 reaches it through Panel 1; subsequent panels follow the same pattern. Forwarded messages preserve each panel's own identity, and acknowledgements travel back along the chain.

That order has a trade-off. If an early panel loses its route, those beyond it also lose theirs. The controlled rollout plan starts with direct enrollment, then tests each additional panel in sequence and deliberately removes one predecessor to check failure and recovery. Read the build note →
