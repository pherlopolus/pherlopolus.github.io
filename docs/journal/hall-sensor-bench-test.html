31 October 2026 · reported bench observation / planned integration

A magnet joins the RPM investigation

The search for an independent RPM signal has reached a simple bench test.

With the KY-003 Hall module powered from 5 V, its output measured about 3.2 V, dropping to 0 V when presented with a magnet. That demonstrates switching in this bench setup; reliable detection of the flywheel magnets remains untested.

The proposed arrangement uses the existing flywheel magnets, with an Arduino Uno feeding the ESP32. The Uno was chosen as easier to package for this trial. Initial code was supplied in chat, but compilation and operation have not been confirmed.

Next comes checking the mounting, clearance and pulses per revolution before comparing readings on the running bike. For now, we have a sensor responding to a magnet—and another useful entry in the notebook.

Evidence

Bench measurements and the proposed Uno arrangement were reported in Phil’s 31 October discussion. This KY-003 trial is separate from the earlier NJK-5002C mounting investigation. The logger’s successful software checks do not validate the Uno trial.
