About

The projects, including the detours.

Bumbling Bimbler is Phil Neal's notebook for motorcycles, embedded electronics and things that looked simple until they were taken apart.

This site gathers the reasoning behind each project: what problem we were trying to solve, what we built, what we measured, and what we still need to check. It is a companion to the Bumbling Bimbler video channel, with room for diagrams, code and downloadable build files as the work matures.

How to read the notes

Planned is a proposal or next step. Code / bench means the design exists as code or has had a limited check. Hardware tested is reserved for an observed result on the actual equipment. A repository README or a successful compile alone is not a motorcycle test.

Older entries are retrospective notes about work done at the stated time. They may be expanded or corrected as original measurements and photographs are recovered.
