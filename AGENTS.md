- This repository is the source of truth for the website. GitHub Pages serves `docs/` from `main`.
- Prepare future posts and material updates on a separate branch/pull request. Do not merge or publish a specific update until Phil explicitly approves it. The initial launch was approved in the website setup conversation on 28 October 2026.
- Keep a chronological record of meaningful CB450 EFI experiments. Describe the problem, what was tried, observed results, and the next step. Include useful failures.
- Research project source repository `pherlopolus/CB450dx-EFI` and available relevant conversations before drafting. Do not infer hardware success from code or compilation.
- Distinguish plans, code/static/bench checks, compilation and physical tests. Label retrospective entries and do not invent exact work dates.
- Private repository access does not authorize copying credentials, customer or staff information, internal operational details, or entire source files onto this public website.
- Keep public project summaries technically accurate, plain spoken, and suitable for a workshop notebook. Preserve Bumbling Bimbler branding.
- Update the journal listing and home page when adding a post, and verify all local links. Keep navigation responsive and accessible.
- If there is no meaningful new work, do not manufacture a post. Report that no update is proposed.

- Current scope: CB450 EFI only. Phil requested removal of message centre pages and links on 28 October 2026. Do not add other projects unless requested.
