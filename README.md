# Bumbling Bimbler

Workshop project notebook for motorcycles and embedded electronics.

Website: https://pherlopolus.github.io/

GitHub Pages serves `docs/` from `main`. The site is static HTML and CSS and needs no build dependencies. Preview locally with `python3 -m http.server 8000 --directory docs`.

New posts and material edits are prepared on a branch or in a pull request for Phil's approval before publication. The daily ChatGPT review runs at 09:00 Europe/London. See `AGENTS.md` for the editorial workflow.
